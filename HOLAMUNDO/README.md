# Actividad 2 - HOLAMUNDO

## Materia
Laboratorio de Programación (LPR)

## Descripción

En esta actividad se realizó la configuración del entorno de desarrollo para programar en C++ utilizando Visual Studio Code.

Se instalaron y configuraron las herramientas necesarias para trabajar con C++, incluyendo las extensiones de VS Code y el compilador MinGW (GCC).

También se creó el primer programa de prueba "Hola Mundo" en C++, ubicado en la carpeta `src/`, y se aprendió a compilarlo y ejecutarlo desde la terminal de PowerShell.

## Estructura del proyecto

- `.gitignore`: indica los archivos y carpetas que Git debe ignorar.
- `README.md`: contiene la descripción y documentación del proyecto.
- `LICENSE`: contiene la licencia del proyecto.
- `Docs/`: contiene la documentación y el informe en PDF.
- `src/`: contiene el código fuente del programa.
- `Capturas/`: contiene las evidencias de la configuración y ejecución.

## Herramientas utilizadas

- Visual Studio Code
- C++
- MinGW / GCC
- PowerShell
- Git
- GitHub

## Objetivo

El objetivo de la actividad es familiarizarse con el entorno de desarrollo, comprender el funcionamiento básico de un compilador y aprender a compilar y ejecutar un programa en C++ desde la terminal.
